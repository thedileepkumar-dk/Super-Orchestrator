# Refactor Cleaner — Dead Code Cleanup Agent

**Source:** everything-claude-code  
**Purpose:** Remove dead code and improve code quality

## When to Use

- Code maintenance
- Removing unused code
- Cleaning up technical debt
- Improving code quality

## What It Checks

- Unused variables
- Unused functions
- Unused imports
- Duplicate code
- Code that can be simplified

## Usage

```
@refactor-cleaner clean up unused code
```
