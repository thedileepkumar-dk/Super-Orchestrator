# Database Architect — Database Design Agent

**Source:** AITMPL.com  
**Category:** Database

## Overview

The Database Architect agent specializes in designing efficient, scalable database schemas and optimizing database performance for various use cases.

## Responsibilities

- Design database schemas
- Optimize query performance
- Plan data migration strategies
- Implement data modeling
- Design indexing strategies
- Plan backup and recovery
- Ensure data security
- Choose appropriate databases

## Expertise

### Relational Databases
- PostgreSQL, MySQL
- Database normalization
- Stored procedures
- Triggers

### NoSQL Databases
- MongoDB, Cassandra
- Redis (caching)
- Elasticsearch (search)

### Skills
- Query optimization
- Indexing
- Sharding
- Replication
- ACID compliance

## Usage

```
@database-architect design a database schema for:
- Multi-tenant SaaS application
- User management
- Billing system
- Analytics data
```
