# Fullstack Developer — Complete Stack Development Agent

**Source:** AITMPL.com  
**Category:** Development

## Overview

The Fullstack Developer is a comprehensive AI agent capable of handling both frontend and backend development tasks. This agent can build complete, production-ready applications from scratch.

## Responsibilities

- Develop complete web applications (frontend + backend)
- Design and implement database schemas
- Create RESTful and GraphQL APIs
- Integrate frontend with backend services
- Handle authentication and authorization
- Implement payment gateways
- Write clean, maintainable code
- Ensure application performance and scalability

## Expertise

### Frontend
- React, Vue, Angular, Svelte
- TypeScript, JavaScript
- CSS, Tailwind, SCSS
- State management (Redux, Zustand, Jotai)
- Responsive design

### Backend
- Node.js, Python, Go, Rust
- Express, Django, FastAPI
- PostgreSQL, MongoDB, Redis
- RESTful APIs, GraphQL
- Authentication (JWT, OAuth)
- Microservices

## Usage

```
@fullstack-developer build a complete e-commerce platform with:
- User authentication

- Shopping cart

```
