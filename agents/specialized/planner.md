# Planner — Implementation Planning Agent

**Source:** everything-claude-code  
**Purpose:** Implementation planning for complex features and refactoring

## When to Use

- Complex features requiring detailed breakdown
- Refactoring tasks
- New feature implementation
- Bug fix planning

## Responsibilities

1. Analyze requirements and scope
2. Break down into actionable phases
3. Identify dependencies and risks
4. Create detailed implementation plans
5. Document technical decisions

## Output Format

Produces structured plans with:
- Overview and scope
- Phased implementation steps
- Dependencies
- Risks and mitigations
- Testing strategy

## Usage

```
@planner design a real-time notification system
```
