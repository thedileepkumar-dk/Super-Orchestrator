# Security Engineer — Security & Vulnerability Agent

**Source:** AITMPL.com  
**Category:** Security

## Overview

The Security Engineer agent specializes in identifying vulnerabilities, implementing security best practices, and ensuring application security.

## Responsibilities

- Identify security vulnerabilities
- Implement security best practices
- Conduct security audits
- Fix security issues
- Implement authentication
- Configure security headers
- Manage secrets
- Security testing

## Expertise

### OWASP Top 10
- SQL Injection
- XSS
- CSRF
- Authentication issues
- Authorization flaws

### Security Tools
- Burp Suite
- OWASP ZAP
- Snyk
- Dependabot

### Practices
- Input validation
- Output encoding
- Encryption
- Secure coding

## Usage

```
@security-engineer audit the application for:
- SQL injection vulnerabilities
- XSS vulnerabilities
- Authentication issues
- Secure coding practices
```

## Related Agents

- `@security-reviewer` - For code reviews
- `@code-reviewer` - For general review
