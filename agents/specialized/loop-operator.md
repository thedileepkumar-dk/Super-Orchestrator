# Loop Operator — Autonomous Loop Execution Agent

**Source:** everything-claude-code  
**Purpose:** Run autonomous loops safely and monitor progress

## When to Use

- Running autonomous loops
- Monitoring long-running tasks
- Iterative improvements
- Continuous refinement

## Capabilities

- Start and monitor loops
- Detect stalls
- Intervene when needed
- Report progress

## Usage

```
@loop-operator improve test coverage to 90%
```
