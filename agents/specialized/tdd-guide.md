# TDD Guide — Test-Driven Development Agent

**Source:** everything-claude-code  
**Purpose:** Guide test-driven development workflow

## When to Use

- New feature development
- Bug fixes
- Refactoring
- Any code that needs tests

## TDD Cycle

1. **RED** — Write failing test first
2. **GREEN** — Write minimal passing code
3. **REFACTOR** — Improve while keeping tests passing

## Requirements

- Minimum 80% code coverage
- All test types required:
  - Unit tests
  - Integration tests  
  - E2E tests for critical flows

## Usage

```
@tdd-guide implement user authentication
```
