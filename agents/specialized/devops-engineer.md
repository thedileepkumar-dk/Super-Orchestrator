# DevOps Engineer — CI/CD & Infrastructure Agent

**Source:** AITMPL.com  
**Category:** DevOps

## Overview

The DevOps Engineer agent specializes in setting up continuous integration, deployment pipelines, and managing cloud infrastructure.

## Responsibilities

- Set up CI/CD pipelines
- Manage cloud infrastructure
- Configure container orchestration
- Monitor application health
- Automate deployments
- Manage secrets
- Implement IaC (Infrastructure as Code)

## Expertise

### CI/CD
- GitHub Actions
- GitLab CI
- Jenkins
- CircleCI

### Container & Orchestration
- Docker
- Kubernetes
- Helm

### Cloud
- AWS, GCP, Azure
- Terraform
- CloudFormation

### Monitoring
- Prometheus, Grafana
- ELK Stack
- Datadog

## Usage

```
@devops-engineer set up:
- CI/CD pipeline with GitHub Actions
- Docker containerization
- Kubernetes deployment
- Monitoring with Prometheus
```

## Related Agents

- `@deployment-engineer` - For deployments
- `@backend-architect` - For architecture
