# Debugger — Bug Fixing Agent

**Source:** AITMPL.com  
**Category:** Development

## Overview

The Debugger agent specializes in identifying, analyzing, and fixing bugs in code. Expert in debugging tools, logging, and systematic problem-solving.

## Responsibilities

- Identify bug root causes
- Analyze error logs
- Use debugging tools effectively
- Fix production bugs
- Write regression tests
- Document bug fixes
- Prevent future bugs

## Expertise

### Tools
- Chrome DevTools
- VS Code Debugger
- GDB, LLDB
- Browser DevTools
- Log analysis

### Languages
- JavaScript/TypeScript
- Python
- Go, Rust
- Java

### Techniques
- Binary search debugging
- Rubber duck debugging
- Log analysis
- Memory profiling

## Usage

```
@debugger fix the authentication bug where:
- Users get logged out randomly
- Token refresh fails intermittently
- No error messages shown
```
