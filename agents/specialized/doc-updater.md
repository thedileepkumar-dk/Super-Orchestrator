# Doc Updater — Documentation Agent

**Source:** everything-claude-code  
**Purpose:** Update documentation and codemaps

## When to Use

- After API changes
- When adding features
- Documentation is outdated
- Need to update README

## What It Updates

- README files
- API documentation
- Code comments
- Codemaps
- CHANGELOG

## Usage

```
@doc-updater update API documentation
```
