# Documentation Expert — Technical Writing Agent

**Source:** AITMPL.com  
**Category:** Documentation

## Overview

The Documentation Expert agent specializes in creating clear, comprehensive technical documentation for codebases, APIs, and projects.

## Responsibilities

- Write API documentation
- Create user guides
- Maintain README files
- Write technical blog posts
- Document code
- Create architecture docs
- Maintain changelogs

### Types of Docs
- API documentation
- User guides
- Developer guides

- README files

### Skills
- Clear writing
- Code examples
- Diagram creation
