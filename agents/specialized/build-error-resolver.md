# Build Error Resolver — Build/Type Error Fixer

**Source:** everything-claude-code  
**Purpose:** Fix build errors and type errors quickly

## When to Use

- Build fails
- TypeScript errors
- Compilation errors
- Linting errors

## Approach

1. Analyze error messages
2. Fix errors incrementally
3. Verify after each fix
4. Check for similar issues

## Usage

```
@build-error-resolver fix the build errors
```
