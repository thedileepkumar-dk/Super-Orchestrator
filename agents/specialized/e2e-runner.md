# E2E Runner — End-to-End Testing Agent

**Source:** everything-claude-code  
**Purpose:** Generate and run Playwright E2E tests

## When to Use

- Testing critical user flows
- Before releases
- After major changes
- Regression testing

## Testing Approach

1. Identify critical user flows
2. Create Playwright tests
3. Use Page Object Model
4. Run tests in CI/CD

## Coverage Requirements

- Login/authentication flows
- Checkout/payment flows
- Critical business logic

## Usage

```
@e2e-runner test the checkout flow
```
