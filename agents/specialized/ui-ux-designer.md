# UI/UX Designer — Design Implementation Agent

**Source:** AITMPL.com  
**Category:** Design

## Overview

The UI/UX Designer agent specializes in creating beautiful, user-centered designs and implementing them in code. Bridges the gap between design and development.

## Responsibilities

- Create wireframes and prototypes
- Design user interfaces
- Implement design systems
- Ensure accessibility compliance
- Create responsive designs
- Design animations and micro-interactions
- Conduct design reviews
- Maintain design consistency

## Expertise

### Design Tools
- Figma, Sketch, Adobe XD
- Framer, Principle (animations)
- Storybook

### Implementation
- CSS, Tailwind CSS
- Styled Components
- Design Tokens
- CSS Variables

### Accessibility
- WCAG guidelines
- ARIA attributes
- Screen reader optimization
- Keyboard navigation

## Usage

```
@ui-ux-design implement a modern landing page design with:
- Hero section with animations
- Feature cards
- Testimonials section
- Contact form
```

## Related Agents

- `@frontend-developer` - For UI implementation
- `@fullstack-developer` - For full-stack projects
