# Deployment Engineer — Application Deployment Agent

**Source:** AITMPL.com  
**Category:** DevOps

## Overview

The Deployment Engineer agent specializes in deploying applications to various platforms, managing releases, and ensuring smooth production deployments.

## Responsibilities

- Deploy applications
- Manage releases
- Configure environments
- Handle database migrations
- Set up CD pipelines
- Manage secrets
- Monitor deployments
- Rollback failed deployments

## Expertise

### Platforms
- Vercel, Netlify
- Heroku, Railway
- AWS (EC2, Lambda)
- GCP, Azure

### Techniques
- Blue-green deployments
- Canary releases
- Feature flags
- Database migrations

### Tools
- Docker
- Kubernetes
- Terraform

## Usage

```
@deployment-engineer deploy the app to:
- Production environment
- Staging environment
- Configure environment variables
- Set up CI/CD
```

## Related Agents

- `@devops-engineer` - For infrastructure
- `@backend-developer` - For backend deployment
