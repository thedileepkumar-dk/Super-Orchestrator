# Android Developer — Android Platform Development Agent

**Source:** AITMPL.com  
**Category:** Mobile Development

## Overview

The Android Developer agent specializes in building native Android applications using Kotlin and Jetpack Compose, with expertise in Google Play deployment.

## Responsibilities

- Build native Android apps
- Implement Jetpack Compose UI
- Integrate Android APIs
- Handle app lifecycle
- Optimize performance
- Manage data persistence
- Implement push notifications
- Deploy to Play Store

## Expertise

### Languages & Frameworks
- Kotlin
- Jetpack Compose
- Java
- Android SDK

### Android Frameworks
- Room
- Hilt/Dagger
- Coroutines
- WorkManager

### Tools
- Android Studio
- Gradle
- Firebase

## Usage

```
@android-developer build an Android app with:
- Material Design 3 UI
- MVVM architecture
- Room database
- Push notifications
```
