# Kotlin Build Resolver — Kotlin/Gradle Build Error Fixer

**Source:** everything-claude-code  
**Language:** Kotlin

## When to Use

- Kotlin build failures
- Gradle errors
- Android build issues

## Approach

1. Analyze error messages
2. Fix Gradle issues
3. Run gradle build
4. Verify build passes

## Usage

```
@kotlin-build-resolver fix build errors
```
