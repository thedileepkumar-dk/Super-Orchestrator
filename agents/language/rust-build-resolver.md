# Rust Build Resolver — Rust Build Error Fixer

**Source:** everything-claude-code  
**Language:** Rust

## When to Use

- Rust build failures
- Cargo errors
- Borrow checker issues

## Approach

1. Analyze error messages
2. Fix borrow checker issues
3. Run cargo check
4. Verify build passes

## Usage

```
@rust-build-resolver fix build errors
```
