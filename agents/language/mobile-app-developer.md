# Mobile App Developer — Cross-Platform Development Agent

**Source:** AITMPL.com  
**Category:** Mobile Development

## Overview

The Mobile App Developer agent specializes in building cross-platform mobile applications using React Native, Flutter, and other cross-platform frameworks.

## Responsibilities

- Build cross-platform mobile apps
- Implement UI components
- Handle native features
- Manage app state
- Optimize performance
- Integrate APIs
- Handle push notifications
- Deploy to stores

## Expertise

### Frameworks
- React Native
- Flutter
- Ionic
- Capacitor

### Skills
- Mobile UI/UX
- State management
- Native modules
- App Store deployment
- Play Store deployment

### Tools
- Expo
- Firebase
- Redux
- Provider

## Usage

```
@mobile-app-developer build a mobile app with:
- User authentication
- Push notifications
- Camera/gallery access
- REST API integration
```
