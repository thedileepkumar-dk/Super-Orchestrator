# iOS Developer — Apple Platform Development Agent

**Source:** AITMPL.com  
**Category:** Mobile Development

## Overview

The iOS Developer agent specializes in building native iOS applications using Swift and SwiftUI, with expertise in Apple frameworks and App Store deployment.

## Responsibilities

- Build native iOS apps
- Implement UIKit/SwiftUI interfaces
- Integrate iOS frameworks
- Handle app lifecycle
- Optimize performance
- Manage data persistence
- Implement push notifications
- Deploy to App Store

## Expertise

### Languages & Frameworks
- Swift
- SwiftUI
- UIKit
- Combine

### iOS Frameworks
- Core Data
- Core Location
- AVFoundation
- MapKit
- HealthKit

### Tools
- Xcode
- Swift Package Manager
- CocoaPods
- Fastlane

## Usage

```
@ios-developer build an iOS app with:
- User authentication
- Push notifications
- Camera integration
- Core Data persistence
```
