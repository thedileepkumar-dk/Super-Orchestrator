# Continuous Learning Skill

**Source:** everything-claude-code  
**Category:** Learning

## Overview

This skill enables automatic extraction of patterns from sessions into reusable knowledge.

## What It Does

- Extract useful patterns mid-session
- Save patterns as skills
- Track learned instincts
- Evolve patterns over time

## Commands

- `/learn` — Extract patterns mid-session
- `/learn-eval` — Extract, evaluate, save patterns
- `/instinct-status` — View learned instincts
- `/instinct-import` — Import instincts
- `/instinct-export` — Export instincts
- `/evolve` — Cluster instincts into skills
- `/prune` — Delete expired pending instincts

## Pattern Categories

- Code patterns
- Workflow patterns
- Tool usage patterns
- Configuration patterns

## Usage

```
/learn extract patterns from this session
```
