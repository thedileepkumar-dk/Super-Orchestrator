# /learn — Extract Patterns

**Source:** everything-claude-code  
**Category:** Learning

## Description

Extract useful patterns from the current session into reusable skills.

## Usage

```
/learn
```

## What It Does

1. Analyzes recent work
2. Identifies reusable patterns
3. Creates skill definitions
4. Saves for future use

## Related Commands

- `/learn-eval` — Extract with evaluation
- `/instinct-status` — View learned patterns
- `/evolve` — Cluster into skills
