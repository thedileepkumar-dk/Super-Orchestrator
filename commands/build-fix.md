# /build-fix — Fix Build Errors

**Source:** everything-claude-code  
**Category:** Build

## Description

Fix build errors and get the build passing.

## Usage

```
/build-fix
```

## Workflow

1. Run build command
2. Analyze errors
3. Fix incrementally
4. Verify after each fix
5. Run full build

## Tools

- TypeScript: `npm run build`
- Go: `go build`
- Rust: `cargo build`
- Java: `mvn build` / `gradle build`
