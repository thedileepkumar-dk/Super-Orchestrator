# /refactor-clean — Dead Code Cleanup

**Source:** everything-claude-code  
**Category:** Refactoring

## Description

Remove dead code and clean up the codebase.

## Usage

```
/refactor-clean
```

## What It Finds

- Unused variables
- Unused functions
- Unused imports
- Duplicate code
- Code that can be simplified

## Best Practices

- Run tests after each change
- Commit frequently
- Don't over-refactor
- Keep changes focused
