# /e2e — End-to-End Testing

**Source:** everything-claude-code  
**Category:** Testing

## Description

Generate and run Playwright E2E tests for critical user flows.

## Usage

```
/e2e test the checkout flow
```

## What It Does

1. Identifies critical user flows
2. Creates Playwright tests
3. Uses Page Object Model
4. Runs tests locally or in CI

## Best Practices

- Test critical paths only
- Use meaningful assertions
- Handle async properly
- Clean up test data

## Related Commands

- `/code-review` — Review test quality
- `/tdd` — TDD for implementation
