# /verify — Verification Loop

**Source:** everything-claude-code  
**Category:** Verification

## Description

Run verification loop to validate implementation against requirements.

## Usage

```
/verify
```

## What It Does

1. Checks implementation against plan
2. Runs tests
3. Verifies coverage
4. Checks security
5. Reports results

## Checkpoints

- Functionality works as expected
- Tests pass
- Coverage meets requirements
- No security issues
- Code quality acceptable
