## Installation - Single Click (Works on ALL Platforms!)

The installer **automatically detects** which platform you're using (OpenCode, Claude Code, Codex, Cursor, or Trae).

### macOS / Linux

```bash
# Auto-detects your platform and installs
curl -fsSL https://raw.githubusercontent.com/thedileepkumar-dk/Super-Orchestrator/main/install.sh | bash
```

### Windows (PowerShell)

```powershell
# Auto-detects your platform and installs
irm https://raw.githubusercontent.com/thedileepkumar-dk/Super-Orchestrator/main/install.ps1 | iex
```

### Manual Installation

```bash
# Clone the repository
git clone https://github.com/thedileepkumar-dk/Super-Orchestrator.git
cd Super-Orchestrator

# Run the installer (auto-detects platform)
./install.sh
```

## Contributing

We welcome contributions! Please see our [Contributing Guide](CONTRIBUTING.md) for details.

### Contributing Guide

#### How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/thedileepkumar-dk/Super-Orchestrator.git`
3. **Create** a feature branch: `git checkout -b feature/amazing-feature`
4. **Make** your changes
5. **Commit** your changes: `git commit -m 'feat: add amazing feature'`
6. **Push** to the branch: `git push origin feature/amazing-feature`
7. **Open** a Pull Request

#### Contribution Types

| Type | Description |
|------|-------------|
| 🐛 Bug Fix | Fix a bug in the codebase |
| ✨ New Feature | Add a new agent, skill, or command |
| 📚 Documentation | Improve docs, README, etc. |
| ♻️ Refactor | Code refactoring |
| 🧪 Tests | Add or improve tests |

#### Code Style

- Use consistent formatting
- Add comments for complex logic
- Follow the existing file structure
- Test your changes before submitting

#### Commit Message Format

```
<type>(<scope>): <description>

Types: feat, fix, refactor, docs, test, chore
```
